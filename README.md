# OnePlayer

#### 介绍
一款界面简洁美观的音乐播放器。


#### 功能介绍
0.  支持循环播放、随机播放、单曲循环。
1.  音量控制：软件可以单曲控制音量大小，独立于系统音量。
2.  播放记忆：软件启动时播放上次退出时正在播放的歌曲，且从退出时的位置开始播放。
3.  拖拽导入：将音乐文件拖入播放器即可添加到播放列表。
3.  封面显示：提取歌曲文件中的图片，显示在界面上，带有毛玻璃效果。
4.  歌曲搜索：按ctrl+F可以在播放列表中，对歌曲名进行搜索。
5.  ncm支持：支持直接播放网易云ncm格式歌曲。


## 安装说明



#### 编译说明
1.  QT版本：6.6.0 \(之前使用6.3.2的msvc编译器时，会发生播放音乐卡顿的现象，6.3.2的mingw编译器就没这个问题\)。
2.  VS版本：2022 \(用QtCreater的话稍作修改应该也能开发，没试过\)。
3.  本项目中还用到了我的另一个项目OneDer，主要用它的DList来代替QList使用。需拉取，并配置包含路径。
4.  使用QMediaPlayer的metaData来获取音乐图片，很多时候会获取不到，所以改用FFmpeg来获取音乐图片。
